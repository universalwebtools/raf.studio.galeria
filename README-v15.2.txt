RAF.studio Galeria v15.2 — STORAGE MONITOR

Nowości w panelu administratora:
- automatyczny licznik aktywnych plików Firebase Storage
- zajęte miejsce względem ustawionego progu (domyślnie 5 GB)
- pasek procentowy: normalny / ostrzeżenie / alarm
- osobno ORYGINAŁY i PREVIEW
- liczba wszystkich plików
- ranking galerii od największej do najmniejszej
- przy każdej galerii informacja „Storage ...”
- przed usunięciem galerii panel pokazuje szacowany rozmiar aktywnych plików
- po uploadzie i usunięciu galerii licznik przelicza się ponownie
- przycisk „Przelicz teraz”
- próg monitorowania GB można zmienić bez kodu

WAŻNE:
Storage Monitor pokazuje aktywne pliki w Firebase Storage, a nie oficjalny rachunek Google.
Nie obejmuje transferu/pobrań.
Soft Delete może powodować, że po usunięciu pliki przez pewien czas nadal zajmują miejsce rozliczeniowe po stronie Google.

Nie trzeba zmieniać:
- Realtime Database Rules
- Storage Rules
- Firebase konfiguracji

Na GitHub podmień pliki z ZIP-a i zrób Ctrl+F5.
